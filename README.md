# arv

ვაქცინაციის კალკულატორი React/Vite-ზე.

## გაშვება

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deployment

Repository: `k8kapanadze/arv`

Custom domain: `arv.imed.com.ge`

GitHub Pages-ში Source უნდა იყოს `GitHub Actions`. `public/CNAME` ფაილი ინარჩუნებს custom domain-ს deploy-ის შემდეგ.
